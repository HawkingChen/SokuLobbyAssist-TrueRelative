# 真实相对（TrueRelative）

在东方非想天则（Touhou 12.3）联机大厅显示玩家评分和相对等级。

评分数据来自 [soku.cleista.cc](https://soku.cleista.cc/)。

## 安装

可通过 SokuLauncher 的“设置 - 下载”安装，也可以将安装包解压到游戏的 `modules` 目录。

## 快捷键

- F7：显示或隐藏相对等级，默认显示。
- F8：切换查看附近玩家。
- F9：显示或隐藏自己的评分框。
- F10：切换自动显示附近玩家及自己的评分框。

`relative-levels.txt` 可以用来调整相对等级的分数线。
